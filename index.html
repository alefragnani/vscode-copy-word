Word-aware commands

Never manually select a word again.

Copy Word in Cursor adds three commands that behave like their native counterparts when text is selected, but automatically target the current word when it is not.

Copy Word: Cut

Cuts the current word when there is no selection, just like a normal cut when there is.

Copy Word: Copy

Copies the current word to the clipboard without requiring you to select it first.

Copy Word: Paste

Pastes clipboard content over the current word, according to your configured paste behavior.

Keyboard shortcuts

Use them as your default Cut, Copy, and Paste shortcuts.

Go to File / Preferences / Keyboard Shortcuts and add entries binding Ctrl/Cmd+C, Ctrl/Cmd+X, and Ctrl/Cmd+V to the extension commands whenever the editor has focus.

Commands to bind

  • copy-word.copy — copy the current word
  • copy-word.cut — cut the current word
  • copy-word.paste — paste over the current word

Scope

Bind each entry with "when": "editorTextFocus" so the shortcuts only apply while editing.

{
  "key": "Cmd+c",
  "command": "copy-word.copy",
  "when": "editorTextFocus"
},
{
  "key": "Cmd+x",
  "command": "copy-word.cut",
  "when": "editorTextFocus"
},
{
  "key": "Cmd+v",
  "command": "copy-word.paste",
  "when": "editorTextFocus"
}

Configurable paste

Choose exactly how paste replaces the current word.

original

  • Keeps the native VS Code paste behavior
  • Inserts clipboard text at the cursor position
  • Leaves the surrounding word untouched

replaceWordAtCursor

  • Default paste behavior
  • Replaces the entire current word with clipboard content
  • Applies regardless of where the cursor sits inside the word

replaceWordAtCursorWhenInTheMiddleOfTheWord

  • Replaces the word only when the cursor is in the middle of it
  • Falls back to inserting normally at word boundaries
  • Useful when you want edge-safe replacement

Original Cut/Copy fallback

  • copyWord.useOriginalCopyBehavior setting
  • Restores native Cut/Copy when no current word is defined
  • false by default

Multi-cursor & web

Consistent word-aware editing everywhere you work.

Copy Word in Cursor applies its Cut, Copy, and Paste logic across every active cursor at once, and runs equally well in desktop VS Code and in browser-based environments like vscode.dev and github.dev.

Multi-cursor support

  • Cut, Copy, and Paste apply to all cursors at once
  • Each cursor uses its own current word when no selection is active
  • Works with any number of cursors

Web support

  • Runs in vscode.dev and github.dev
  • Supports multi-cursor editing in the browser
  • Same behavior as desktop VS Code

FAQ

Quick answers for common questions.

What happens if I already have text selected?

The commands behave just like the native Cut, Copy, and Paste when there is an active selection. The current-word behavior only kicks in when there is no selection at all.

How do I make these my default Cut/Copy/Paste shortcuts?

Open File / Preferences / Keyboard Shortcuts and add entries binding Ctrl/Cmd+C, Ctrl/Cmd+X, and Ctrl/Cmd+V to copy-word.copy, copy-word.cut, and copy-word.paste with "when": "editorTextFocus".

Can I control how Paste replaces the current word?

Yes. Use the copyWord.pasteWordBehavior setting to choose between original, replaceWordAtCursor, or replaceWordAtCursorWhenInTheMiddleOfTheWord.

Can I keep the original Cut/Copy behavior?

Yes. Enable copyWord.useOriginalCopyBehavior to fall back to the native Cut/Copy behavior when no text is selected and no current word is defined.

Does it work with multiple cursors and in the browser?

Yes. Copy Word in Cursor supports multi-cursor editing and runs in web-based VS Code environments in addition to the desktop version.

Does it work on VS Code forks like Cursor, Windsurf, and Antigravity?

Yes! It works on all VS Code forks, ensuring compatibility and seamless integration with your favorite tools.
